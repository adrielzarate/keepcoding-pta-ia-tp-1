# Instructions for AI coding tools

The portfolio workflow is kept once, in [`portfolio-development/SKILL.md`](portfolio-development/SKILL.md), with its detailed planning and testing references beside it.

Claude Code and Codex discover project skills from different directories. Their small entry files in `.claude/skills/portfolio-development/` and `.agents/skills/portfolio-development/` point to this shared source. Keep those entry files when changing the skill's name or purpose, and edit the shared source rather than copying its full instructions into either tool-specific directory.
